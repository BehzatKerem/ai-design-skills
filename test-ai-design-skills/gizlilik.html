How personal notes stay

This page keeps a note in the browser. It does not send that note to FILORA Group.

Which fields exist

The form asks for name, company, mail, phone, use, metres, and a note. Phone and note are optional.

Where it goes

The request is not sent to a server. The latest note stays only in your browser storage. Writing a new request deletes the previous note. You can also clear it in the browser settings.

Cookies

We do not set a required cookie or an advertising cookie. Browser storage is not a cookie. It stays only on your device.
